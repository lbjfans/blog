# 任务

分类
通过先验求后验概率
- 先验：常识，如全概率公式
- 后验：已知A发生，求B引起的概率；如贝叶斯公式

```
3.下列关于朴素贝叶斯分类器错误的是（ D ）
A.朴素贝叶斯模型发源于古典数学理论，有稳定的分类效率
B.对小规模的数据表现很好，能个处理多分类任务，适合增量式训练
C.对缺失数据不太敏感，算法也比较简单，常用于文本分类
D.对输入数据的表达形式不敏感

适用于小规模
表达敏感，如不适用于条件独立假设
```

正向概率：假设N个白球，M个黑球，求黑球的概率
逆向概率：不知道黑白球比例，摸出几个球后推测总体的比例
