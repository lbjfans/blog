# 查找

查找过程，判定树，平均查找长度（成功、失败）

顺序查找
- 成功：(1 + 2 ... + n) / n = n(n+1) / 2
- 失败：n 
- 考点1：可以将0位置作为哨兵，从后往前查找
- 考点2：提前break

折半查找
- 二叉排序树，AVL，判定树唯一；如何判断判定树是否为折半查找：可以代入值，观察是否符合都是向上/下取整
- 比较次数不超过树高$\lceil log_2(n+1) \rceil$
- 左子树和右子树元素个数相同，或左+1=右（左-1=右）
- 成功：按层数，(1 * 1 + 2 * 2 ...  ) / n
- 失败：叶子节点的层数，可能是最后一层/倒数第二层

分块查找
- 第一次顺序or折半找块
- 第二次块内找数据
- $s = sqrt(n)$的ASL最小

# 哈希表

哈希函数

处理冲突
- 线性探测：插入时，遇到冲突就找下一个位置；删除时，做标记，因为可能删除了插入冲突时的元素

装填因子（存储效率） = 表中记录数（题目给出的序列） / 长度（槽位）

ASL成功：每个关键字探测次数之和 / 关键字个数
ASL失败：min{ 槽位，散列地址（序列个数，mod num）}；如散列到每个槽位，失败的次数 / 长度
- 空位置也要比较

# B tree 

m阶：m叉树，至多m个子树，至多m-1个关键字

中间节点关键字范围：$[\lceil m/2 \rceil - 1, m - 1]$
- 根节点至少1个关键字
树的高度，节点个数，关键字个数的关系
- 给定m阶，可知关键字范围，以及子节点个数
- 考点：至多，至少
插入
- 直接插入
- 分裂：$\lceil {n/2} \rceil$到父节点
删除
- 不在叶子节点：用左孩子最右 / 右孩子最左 替换
- 叶子节点
	- 直接删除
	- 借：兄弟节点和父节点
	- 合并：父节点和兄弟节点；如果合并后父节点也小于最小关键字个数，递归合并

# 树形查找

BST 二叉排序树（查找）：左小右大（左边所有节点的值都小于根节点）；15年题目AVL不是BST
- 中序遍历：有序序列
- 插入顺序不同，判定树不唯一
- 删除：三种情况；1. 叶节点，直接删除；2. 只有左/右子树，用子树填补；3. 如果左右子树不为空，为了保证中序遍历同，选中序第一个子节点（左子树最右，或右子树最左）填补，然后递归删除该节点
- 如果只有左/右子树，则平均查找长度为O(n)

平衡二叉树（AVL树）
- 左右子树高度差<=1，平衡因子为-1/0/1，ASL：O($log_2n$)；
- 深度和最少结点数：找规律，$n_h = n_{h-1} + n_{h - 2} + 1$；$n_h$记为深度为h的AVL的最少节点数，n0 = 0, n1 = 1, n2 = 2, n3 = 4, n4 = 7
- 删除叶节点，然后重新插入，可能不同；删除非叶节点，然后插入，可能相同
- 插入后，对路径上离插入节点最近的不平衡的节点进行调整（检查，BST以及平衡因子）
	- LL：左孩子的左子树，右单（和LL反着来 ）旋转
	- LR：左孩子右子树，先左后右（同LR，左孩子L，不平衡节点R）旋转
	- RL：右孩子左子树，先右后左旋转
	- RR：右孩子右子树，左单旋转
- 删除
	- 删除后依然平衡（同BST）
	- 不平衡，对不平衡的节点进行LL, LR, RL, RR的操作（z是不平衡节点，y是z中高度最高的孩子节点，x是y高度最高的叶子节点）

## 插入排序

类似整理卡牌顺序
```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        // 插入排序
        int n = nums.size();
        for(int i = 1; i < n; i++){
            int key = nums[i];
            int j = i - 1;
            while(j >= 0 && nums[j] > key){
                nums[j + 1] = nums[j];
                --j;
            }
            nums[j + 1] = key;
        }
        return nums;
    }
};
```

时间：O($n^2$)，对于接近有序的数组，只需要遍历，复杂度可为O(n)
空间：O(1)

稳定性：稳定
适用：顺序、链表

## 冒泡排序

代码
```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        int n = nums.size();
        for(int i = 0; i < n - 1; i++){  // n-1趟
            bool flag = false;
            for(int j = n - 1; j > i; j--){  // 小的往前面冒泡
                if(nums[j - 1] > nums[j]){
                    swap(nums[j - 1], nums[j]);
                    flag = true;
                }
            }
            if(flag == false){
                break;
            }
        }
        return nums;
    }
};
```
可视化：从后往前冒泡

时间：最差（逆序）O($n^2$)，比较次数为$n(n - 1) / 2$，移动次数 = 3 * 比较次数
空间：O(1)

稳定性：稳定
适用：顺序、链式


## 快速排序

[912. 排序数组 - 力扣（LeetCode）](https://leetcode.cn/problems/sort-an-array/)

快速排序
```cpp
class Solution {
public:
    void quickSort(vector<int>& nums, int l, int r){
        if(l >= r) return;
        int x = nums[l], i = l, j = r;  // 如果要换主元，需要先换到最左边
        while(i < j){
            while(i < j && nums[j] >= x) --j;  // 找小的
            nums[i] = nums[j];
            while(i < j && nums[i] <= x) ++i;  // 找大的
            nums[j] = nums[i];
        }
        nums[i] = x;
        quickSort(nums, l, i - 1);
        quickSort(nums, i + 1, r);
    }
    vector<int> sortArray(vector<int>& nums) {
        // 快排
        quickSort(nums, 0, nums.size() - 1);
        return nums;
    }
};
```
可视化
- 一趟之后，主元到达目标位置，且左边的数比他小，右边的比他大
- 第一趟后，如果主元是l或r，那么第二趟起码可以确定至少2个元素的位置
- 如果主元是中间值，那么第二趟起码可以确定3个元素的位置(两边都快排)
```
49, 38, 65, 97, 76, 13, 27
找主元：49
右边找大的和主元换位置：27, 38, 65, 97, 76, 13(j), 49
左边找小的和主元换位置；27, 38, 49, 97(i), 76, 13, 65
右边：27, 38, 13, 97, 76(j), 49, 65
左边：27, 38, 13, 49, 76(i, j), 97, 65
停止，递归运行{27, 38, 13}以及{76, 97, 65}
```
可以用二叉树描述递归过程

空间：O($log_2(n)$)，最差O(n)，即排序好的数组
时间：O($n * log_2(n)$)，最差O($n^2$)，即排序好的数组

稳定性：不稳定
实用性：顺序存储

## 简单排序

代码
```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        int n = nums.size();
        for(int i = 0; i < n - 1; i++){  // n -1 趟
            // 找最小的数
            int min_id = i;
            for(int j = i + 1; j < n; j++){
                if(nums[min_id] > nums[j]){
                    min_id = j;
                }
            }
            if(min_id != i) swap(nums[min_id], nums[i]);
        }
        return nums;
    }
};
```
可视化：n-1趟，每趟都找最小的数

时间：O($n^2$)
空间：O(1)

稳定性：不稳定
适用：线性、链表

## 堆排序

完全二叉树，根节点最大/最小

建堆，调整(down)，插入(up)
- 递增排序：建立大堆，堆顶每次都放到最后
- 插入：插到末尾，然后up
- 建堆：注意顺序是从len到根节点0，即每层从右到左down
```cpp
class Solution {
public:
    void down(vector<int>& nums, int k, int len){
        int t = k;
        if(k * 2 + 1 <= len && nums[k*2+1] > nums[t]) t = k*2+1;
        if(k * 2 + 2 <= len && nums[k*2+2] > nums[t]) t=  k*2+2;
        if(t != k){
            swap(nums[t], nums[k]);
            down(nums, t, len);
        }
    }
    vector<int> sortArray(vector<int>& nums) {
        int n = nums.size() - 1;
        for(int i = n / 2; i >= 0; i--){  // 建大堆
            down(nums, i, n);
        }
        // 输出
        for(int i = n; i >= 1; --i){  // 最大的数放到最后面
            swap(nums[i], nums[0]);
            --n;
            down(nums, 0, n);
        }
        return nums;
    }
};
```

## 基数排序

如三位数排序，按个位、十位、百位（LSD）排序（也可以用MSD，即百十个），三次分配和收集

空间：O(r)，r是基数

稳定性：稳定
