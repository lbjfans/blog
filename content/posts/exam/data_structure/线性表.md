# 栈

定义：先进，后出

分类
- 顺序
- 链
- 共享

基本操作
- 初始化：栈顶指针
- 判断空
- 入栈
- 出栈
- 获取栈顶元素

考点
- n个不同元素进栈，出栈的不同排列（卡特兰数）$1/(n+1) * C_{2n}^n$
- 先序序列a,b,c,d的不同二叉树个数：入栈是前序，出栈是中序


# 队列

定义：FIFO

分类
- 顺序
- 链
- 循环
- 双端队列：一端输入/输出受限

基本操作
- 初始化：队头和队尾指针
- 判空：rear == front，也可能是
- 判满（循环队列）：(rear + 1) % n == front；增设size变量；用tag判断rear == front
![600](/blog/images/Pasted%20image%2020241111190334.png)
- 入队
- 出队
- 获取队头元素：front
- 长度：rear - front；循环：(rear - front + n) % n

考点
- 队头队尾
	- 循环：rear分先++后赋值，或先赋值后++；`(++rear) % n`
	- 队头出，队尾进
- 双端队列
- 和栈结合

![](/blog/images/Pasted%20image%2020241108132012.png)
- rear进队列；一个数据进入队列后，rear指向它，所以是先++后赋值

# 数组

定义：相同数据类型的元素构成的有限序列

分类（特殊矩阵）
- 对称
- 三角
- 三对角：第一行和最后一行两个元素，其他三个
![](/blog/images/Pasted%20image%2020241112211145.png)
- 稀疏：存非零元素，包括行，列，数值的三元组；以及存数组的行和列
