# 考纲

树：基本性质、常用存储结构、遍历算法、二叉树、二叉查找树、堆、二叉平衡树、多路树（B树）

# 基本概念

结点的度：孩子个数（边）
树的度：结点最大度数

结点数(n0 + n1 + n...) = 度数(0*n0 + 1*n1 + 2*n2 ...) + 1

森林：多个树的集合

二叉树
- 完全二叉树：n1 = 1 or 0；最后一个叶节点$\lfloor n/2 \rfloor$；注意叶节点可能是最后一层/倒数第二层
- 满二叉树
- 正则二叉树：度只有0 or 2
- n0 = n2 + 1：因为n0 + n1 + n2 = 1 * n1 + 2 * n2 + 1

# 树和森林

存储
- 双亲
- 孩子
- 孩子兄弟：树 > 二叉树，即左孩子右兄弟；森林 < - > 二叉树

树的后序遍历（访问子树，然后访问根节点） > 森林的后序 > 二叉树的中序
树先序 = 森林先序 = 二叉树先序

# 应用

> 节点的带权路径长度：权值 * 到根节点的距离
> 树的带权路径长度WPL：**叶节点**的带权路径长度之和

哈夫曼树：带权路径长度（WPL）min的**二叉树**，可能有多个；加权平均长度（WSL / sum(**频次**)）
- 构造：选2个权值最小的节点
- 权值为0：不成立，因为编码的频率>0，不然不会出现；其次可以用0带入验证建树，矛盾
哈夫曼编码：左0右1（并没有明确规定）；哈夫曼树 > 编码（建树，注意左右01可以互换）
- 固定编码
- 可变长度编码
- 前缀编码：没有一个编码是另一个的前缀
