# 教材考点总结

## 概念

关系模型：关系数据结构，关系操作集合（查询、更新（包括：插入、删除、修改）），关系完整性约束组成

域：相同数据类型的值的集合，如自然数、{男、女}

笛卡尔积：不同域的运算，某些域可以相同；如导师{a, b} x 研究生{c, d} = {(a c), (a d), (b c), (b d)}
- 基数：域的取值个数，如基数（导师）= 2

关系：笛卡尔积的子集
关系模式：R(U, D, DOM, F)，关系名，属性名，域，属性>域，函数依赖
关系数据库：型是模式，值是某一时刻的关系的集合

元组：关系中的一行

属性：关系中的一列，域可以相同，所以属性加以区分

候选码：某一属性组可以唯一的标识一个元组，而他的子集不能
- 超码：自己 or 子集可以唯一标识一个元组
- 对应主属性

主码：多个候选码之中的一个

外码：关系R1的属性组F，与关系R2的**主码**对应

## 关系的完整性

实体，参照，用户定义

实体：如果A是R的主属性，则不能为空

参照：F是R关系（参照关系）的外码，与S关系（被参照关系，目标关系）的主码对应；F必须取值：空值，等于S的主码值
- 学生（学号，姓名，专业号）；专业（专业号，专业名）；此时学生的专业号为空表示还没有分配专业
- 学生（学号，姓名），课程（课程号，课程名），选修（学号，课程号，成绩）；此时外码也为主码，不能为空

用户定义：某一具体应用的数据必须满足的语义要求
- 如上述学生--专业表，可以定义学生姓名也不能为空

## SQL

SQL特点
- 综合统一：DDL（定义）, DQL（查询）, DML（操纵）, DCL（控制）
- 高度非过程化
- 面向集合操作
- 独立的语言/ 嵌入式语言
- 语言简洁
![](/blog/images/Pasted%20image%2020240724181252.png)

区分数据库和模式和表
- MYSQL数据库和模式相同，模式包括表、视图、索引等
- PostgreSQL一个数据库包括多个模式，通常一个用户一个模式

DDL
- 模式定义，表定义，视图定义，索引定义
- 更新数据字典（定义信息，如模式定义等）的信息

![](/blog/images/Pasted%20image%2020240724181810.png)

模式
```mysql
create schema tim;
create database tim;
drop schema tim cascade/restrict;  # 全部删除 / 没有相关的表or视图才可以删除

```

基本表
```mysql
create table student(
	sno char(9) primary key,
	sname char(20) unique,
	ssex char(2),
	sage smallint,
	sdept char(20)
);

create table course(
	cno char(4) primary key,
	cname char(40),
	cpno char(4),
	ccredit smallint,
	foreign key (cpno) references course(cno)
);

create table sc(
	sno char(9),
	cno char(4),
	grade smallint,
	primary key (sno, cno),
	foreign key (sno) references student(sno),
	foreign key (cno) references course(cno)
);

-- 增删改
alter table student add s_entrance date;

alter table student alter column sage int;  # mysql中alter改为modify

alter table course add unique(cname);

-- 不同数据库处理R/C的方式不同
drop table student cascade/restrict;

-- 建立索引，默认ASC
create unique index stusno on studeng(sno);
create unique index scno on sc(sno ASC, cno DESC);
alter index scno rename to xxx;
drop index xxx;
```


视图
- 从一个或几个基本表导出的表，数据库只存放视图的定义
- 优点：简化操作，提供数据的多个角度，安全保护，逻辑独立性
- 可以更新的视图：行列子集视图

## 安全性

安全性：防止不合法使用造成数据泄露、更改或破坏

安全性控制的方法和技术
- 身份鉴别：静态口令、动态口令等
- 多层存取控制
	- 自主存取控制（DAC）：用户对数据对象的存取权限；如revoke, grant, role(权限)
	- 强制（MAC）：用户（主体）和数据对象（客体）都有密级（敏感度标记）；用户密级高(>=)能查看数据，低（<=）能写入数据
	- 推理控制：避免MAC的缺陷，如通过职级可以直到工资
- 视图：隐藏数据
- 审计：对操作记录，可以找出非法存取数据的人、时间和内容
- 数据加密：对存储和传输的数据加密；原始数据（明文） > 密文


## 完整性

完整性：正确性（符合现实语义）和相容性（同一对象在不同关系表中的数据符合逻辑）；防止数据库中有不符合语义的数据

DBMS的完整性机制
- 定义完整性约束
- 检查
- 违约处理

实体完整性：违反 > 拒绝执行
- 主码唯一
- 主码不为空
