# 教材考点总结

## 四个基本概念

数据：描述事物的符号记录
数据库（database）：大量数据的集合
数据库管理系统（DBMS）：系统软件，从数据库中科学组织、获取和存储数据；DDL, DQL, DML, DCL（安全性保护、完整性检查、并发控制、数据库恢复）
数据库系统（DBS）：应用程序，DBMS，数据库，DBA组成的系统

使用DBMS的好处
- 提高开发的效率
- 减轻DBA负担
- 逻辑结构改变，不用改变应用程序；如两个程序使用两个外模式（属于同一个模式），一个程序的增删改不影响另一个，而模式的字段改变也不影响程序的运行

DBMS特点
- 数据结构化：有定义，数据类型；这是和文件系统的本质区别
- 共享性高，冗余度低，易扩充
- 数据独立性高：逻辑，物理
- 等

## 历史

人工管理阶段：数据不保存
文件系统
数据库系统

文件系统和数据库系统区别
- 文件系统面向某一应用；适用于功能简单的应用，如手机的照片、微信数据；FS的数据独立性是应用对应不同的文件
- 数据库面向整个企业等；共享性高，冗余度低，易扩充；数据结构化；数据独立性（物理，逻辑）
联系
- FS和DBMS都是管理数据的软件
- 最终都是对文件操作

## 数据模型

数据模型包括三种模型
- 概念
- 逻辑
- 物理

概念模型：现实世界建模成信息世界
- ER图
逻辑模型：数据结构，数据操作，完整性约束
- 格式化模型：基本层次联系，即两个记录和他们之间一对多的联系
	- 层次：IBM的IMS数据库管理系统，最早的模型
	- 网状
- 关系
物理模型

层次模型
- 数据结构：树状
- 操作：增删改查
- 完整性约束：插入时子节点需要插入双亲，删除双亲需要删除子节点
- 优点：简单，查询效率高，完整性支持
- 缺点：不适用于节点间有多对多联系，查询子节点必须通过双亲
```
	国家
	|     |
	省    直辖市
	|
	市
```

网状模型
- 数据结构：图
- 优点：多对多联系，存取效率高
- 缺点：结构复杂，用户需要了解路径
```
学生    课程
|       |
选课记录
```

关系模型
- 二维表
- 优点：严格的数学概念；存取路径对用户透明，简化了用户工作
- 缺点：路径透明可能造成查询效率低
```
关系名（属性1，...，属性n）
```


## 模式

三个模式
- 外模式：子模式，用户模式；又可以对应多个用户
- 模式：逻辑模式，公共视图
- 内模式：存储模式

两层映像
- 外/模：逻辑独立性；模式改变，外模式不用修改，只需要修改映像
- 内/模：物理独立性；存储结构改变，模式不变，只需要修改映像
