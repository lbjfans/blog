# 1.2 输入输出

用标准库提供IO：cin、cout、cerr、clog
- cout: 可以重定向到文件中
- cerr: 紧急时候用，输出到显示器，不进入缓冲区
- clog: 输出到显示器，先进入缓冲区
- 缓冲区：减少刷屏的次数，多个字符同时输出到显示器
```
int main(){
    cout << "hello world" << endl;
    cerr << "haha" << endl;
    clog << "hahaha" << endl;
    return 0;
}

// 测试, xxx是执行程序
./xxx > test.log

// 结果：显示了ha和haha；而文件中只有hello world
```

# 1.4控制流

while

for：常用于确定循环次数

读取不定个数的输入：当cin遇到EOF/输入错误，返回false，while停止，`ctrl + Z or ctrl + D`
- EOF：如`ret = scanf("%d", &x)`，输入1返回1，输入a返回0，输入`ctrl+D`返回-1；cin的原理相同
```cpp
int main(){
    int ret = 0;
    int p = 0;
    while(cin >> p){
        ret += p;
    }
    cout << ret;
    return 0;
}
```

[std::basic_istream<CharT,Traits>::operator>> - cppreference.com](https://en.cppreference.com/w/cpp/io/basic_istream/operator_gtgt)
- 输入字符后的两步：置为零/min/max，设置failbit

输入double > int
- [cin将小数输入给整形变量(cin>>float to int)_用cin输入整型变量-CSDN博客](https://blog.csdn.net/jingwei163/article/details/79706702)


```cpp
    int p = 1;
    while(p != 5){  // 改为0
        cout << p << endl;
        cin >> p;
    }
```
- 输入a，无限循环输出0
- [C++笔记——io流条件状态_c++的io条件状态-CSDN博客](https://blog.csdn.net/CreateUserName_Keep/article/details/78831687)
- 可以观察operator>>的源码：可以理解为goodbit是000，failbit是010，所以第一次循环设置了failbit后，后面的每一次循环都是failbit，而p被设置为0
- 可以修改循环停止条件为`p != 0`：发现第二次就停止了循环
- 如果需要检查，需要`cin.clear和cin.ignore`
